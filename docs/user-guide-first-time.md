# คู่มือใช้งาน "กระเป๋าตามติด" สำหรับผู้ใช้ครั้งแรก

เขียนจากหน้าจอแอปจริง 4 แท็บ: **กล้อง · เจ้าของ · บอร์ด · ตาม** (ภาพหน้าจอที่ผู้พัฒนาส่งมา)
คู่มือนี้ไม่พูดเรื่องการติดตั้ง สำหรับการเตรียมระบบ (เซิร์ฟเวอร์ เฟิร์มแวร์ ไฟ) ดู `docs/work-report-2026-11-18.md` ส่วนที่ 2

> **หมายเหตุ:** ปุ่มและข้อความด้านล่างตรงกับภาพหน้าจอที่เห็น ส่วนข้อความสถานะที่เปลี่ยนหลังต่อบอร์ดหรือเริ่มตาม ผู้เขียนยังไม่เคยเห็นจริง จึงบรรยายเป็นความหมายคร่าว ๆ ถ้าข้อความบนจอต่างจากที่เขียน ให้เชื่อข้อความบนจอ

---

## 1. กระเป๋าใบนี้ทำอะไร

กระเป๋าเดินตามเจ้าของเอง มีมือถือติดอยู่บนกระเป๋า กล้องมือถือมองหาเจ้าของ แล้วสั่งล้อให้เดินตามไป ถ้าไม่แน่ใจว่าเป็นใคร หรือมีอะไรผิดปกติ กระเป๋าจะ **หยุดเอง**

## 2. ความปลอดภัย (อ่านก่อนใช้ทุกครั้ง)

- ใช้ในที่โล่ง พื้นเรียบ **ทดสอบครั้งแรกโดยยกล้อให้ลอยพ้นพื้น**
- **มีคนคอยถือ/อยู่ใกล้สวิตช์ E-STOP บนตัวกระเป๋าตลอด** สวิตช์นี้ตัดไฟมอเตอร์จริง ใช้ได้แม้มือถือหรือ Wi-Fi ค้าง ส่วนปุ่ม "หยุด!" บนจอพึ่งมือถือและสัญญาณ ไม่ควรใช้เป็นตัวเดียว
- **กระเป๋ายังไม่มีเซ็นเซอร์กันชน** มองไม่เห็นสิ่งกีดขวางหรือคนที่อยู่ด้านหลัง เจ้าของต้องคอยดูทางให้
- อย่าใช้ใกล้เด็ก ทางน้ำ ทางลาด หรือขั้นบันได
- เจ้าของเดิน **ช้า ๆ ตรง ๆ** ไม่ซิกแซ็ก และไม่ให้คนอื่นเดินตัดระหว่างเจ้าของกับกล้อง

## 3. หน้าจอหลัก

| ส่วน | ความหมาย |
|---|---|
| แถบบนสุด **"ยังไม่ต่อบอร์ด · สาธิต"** | สถานะการเชื่อมกับกระเป๋า "สาธิต" คือโหมดสาธิต ปุ่มเฟืองด้านขวา = การตั้งค่า (สำหรับผู้พัฒนา) |
| กรอบภาพมืด **"กดเปิดกล้องเพื่อเริ่ม"** | ภาพจากกล้องมือถือ จะแสดงเมื่อกดเปิดกล้อง |
| กล่องขวา **"จอด"** · **"ยังไม่พร้อม"** | สถานะของกระเป๋า (จอด = หยุดนิ่ง) และข้อความอธิบาย เช่น "ยังไม่ได้ตรวจจับ เริ่มกล้องก่อน" |
| **ยกเลิกที่เลือก** | เลิกเลือกคนที่กำลังตามอยู่ (ตอนนั้นกระเป๋าจะหยุด) |
| แท็บ **กล้อง / เจ้าของ / บอร์ด / ตาม** | ขั้นตอนใช้งาน เรียงตามลำดับ 1 → 4 |
| ปุ่มแดงใหญ่ **หยุด!** | หยุดทันที อยู่ทุกแท็บ |

## 4. ใช้งานทีละขั้น

### ขั้นที่ 1 · แท็บ "กล้อง"
1. **ตั้งมือถือบนกระเป๋าให้หันไปทางเจ้าของ** (ตามข้อความบนจอ) ให้เห็นภาพตัวคนชัด ไม่ถูกบัง
2. กด **"เปิดกล้อง"** ภาพจะขึ้นในกรอบ (อนุญาตการใช้กล้องถ้ามือถือถาม)
3. เจ้าของยืนห่าง **ประมาณ 2–3 เมตร** ให้เห็นทั้งตัว
4. ปุ่ม **"ปิดกล้อง"** ใช้ตอนเลิกใช้

### ขั้นที่ 2 · แท็บ "เจ้าของ" (บอกกระเป๋าว่าใครคือเจ้าของ)

ข้อความบนจอบอกไว้ว่า: *แตะตัวเองในภาพ แล้วกด "จำเสื้อผ้า" หันข้างหรือหันหลังแล้วกด "+ มุม"*

1. **แตะที่ตัวเอง** ในภาพกล้อง จะมีกรอบสีส้มล้อมตัว (หมายถึงเลือกแล้ว)
   - ถ้ากรอบไปอยู่ที่คนอื่น กด "ยกเลิกที่เลือก" แล้วแตะใหม่
2. กด **"จำเสื้อผ้า"** ให้ระบบจำรูปลักษณ์ของคุณตอนนี้ (ทำตอนยืนคนเดียวในภาพ ไม่มีคนอื่นซ้อน)
3. **หันข้างหรือหันหลัง** แล้วกด **"+ มุม"** ทำซ้ำทีละมุม (หน้า ข้าง หลัง) ยิ่งมีหลายมุม ยิ่งหาคุณเจอง่ายเมื่อหลุดแล้วกลับมา
4. ดูตัวเลขในช่องรายชื่อ เช่น **"ผู้ใช้ 1 · หน้า 0 · Re-ID 0 · เสื้อ 0"** ตัวเลขเพิ่มขึ้นเมื่อจำได้มากขึ้น (เสื้อ = จำนวนมุมสีเสื้อผ้า, Re-ID = จำนวนมุมรูปร่างตัวคน, หน้า = ใบหน้า ซึ่งใช้เมื่อเปิดโหมดเต็มเท่านั้น)
5. ปุ่มอื่นในแท็บนี้
   - **ช่องรายชื่อ ("ผู้ใช้ 1") และปุ่มดินสอ**: เลือกผู้ใช้ (มีได้ 3 คน ใช้ได้ทีละคน) และเปลี่ยนชื่อ
   - **"หาเจ้าของ"**: ให้ระบบหาเจ้าของให้เองเมื่อหลุดออกจากภาพแล้วกลับเข้ามา (ยืนนิ่ง ๆ ในภาพสัก 3–5 วินาที)
   - **"ลืมเจ้าของ"**: ลบข้อมูลที่จำไว้ทั้งหมด ใช้เมื่อเปลี่ยนเสื้อผ้าหรือเปลี่ยนเจ้าของ

> ข้อมูลที่จำไว้อยู่ในมือถือเครื่องนี้เท่านั้น (ไม่ส่งออกไปไหน ไม่เก็บรูป) เปลี่ยนเสื้อผ้า ให้ลืมเจ้าของแล้วจำใหม่

### ขั้นที่ 3 · แท็บ "บอร์ด" (เชื่อมมือถือกับกระเป๋า)
1. ช่องที่อยู่ของบอร์ดมีค่าเดิมอยู่แล้ว เช่น `ws://192.168.137.50:81/ws` (ผู้ตั้งระบบกำหนดให้ อย่าแก้ถ้าไม่จำเป็น)
2. กด **"ต่อบอร์ด"** รอจนแถบบนสุดไม่ขึ้นว่า "ยังไม่ต่อบอร์ด" แล้ว
3. **"เลิกต่อ"** ใช้ตอนเลิกใช้ (สำคัญ: กดเลิกต่อทุกครั้ง ไม่งั้นหน้านี้จะพยายามต่อใหม่เอง และคนอื่นต่อกระเป๋าไม่ได้)
4. มือถือและกระเป๋าต้องอยู่ใน Wi-Fi เดียวกัน ถ้าต่อไม่ได้ ให้ดูส่วนแก้ปัญหา

### ขั้นที่ 4 · แท็บ "ตาม"
1. ปุ่ม **"ออกเดินตาม"** กดได้หลังต่อบอร์ดแล้วเท่านั้น (ข้อความใต้ปุ่มบอก: *ต่อบอร์ดก่อน แล้วปุ่มนี้จะกดได้*)
2. ก่อนกด ตรวจว่ากรอบสีส้มอยู่ที่ตัวคุณ (ขั้นที่ 2)
3. กด **"ออกเดินตาม"** แล้ว **เดินไปข้างหน้าช้า ๆ** กระเป๋าจะตามหลัง
4. เลิก: กด **"หยุด!"** หรือกลับไปกดเลิกต่อที่แท็บบอร์ด

## 5. กระเป๋าจะหยุดเอง เมื่อไหร่ (ไม่ใช่อาการเสีย)

- เจ้าของหลุดออกจากภาพ หรือถูกคนอื่นบัง (กระเป๋าไม่เดาเอง)
- เจ้าของเข้ามาใกล้กระเป๋ามากพอ
- เจ้าของอยู่ไกลเกินไปจนตัวเล็กในภาพ
- ระบบไม่แน่ใจว่าใครเป็นเจ้าของ (เช่น คนอื่นแต่งตัวคล้ายกัน)
- สัญญาณ Wi-Fi สะดุดหรือขาด หรือกล้องหยุดส่งภาพ
- กดปุ่ม "หยุด!" หรือสวิตช์ E-STOP

พอหยุดแล้ว ให้กลับมายืนในภาพกล้องนิ่ง ๆ แล้ว **แตะตัวเองใหม่** (หรือกด "หาเจ้าของ") แล้วกด "ออกเดินตาม" อีกครั้ง

## 6. แก้ปัญหาเบื้องต้น

| อาการ | ทำอย่างไร |
|---|---|
| กล้องไม่ขึ้นภาพ | กด "เปิดกล้อง" อีกครั้ง อนุญาตสิทธิ์กล้องในเบราว์เซอร์ ปิดแอปอื่นที่ใช้กล้อง |
| แตะตัวเองไม่ติด (ไม่มีกรอบส้ม) | ยืนห่าง 2–3 เมตรให้เห็นทั้งตัว ในที่สว่าง แล้วแตะกลางตัวอีกครั้ง |
| "ต่อบอร์ด" ไม่ได้ / บอกว่าบอร์ดไม่ว่าง | มีคนหรืออุปกรณ์อื่นต่อกระเป๋าอยู่ ปิดหน้านี้บนเครื่องอื่นให้หมด รอ 5 วินาที แล้วกดต่อใหม่ ตรวจว่า Wi-Fi ของมือถือเป็นตัวเดียวกับกระเป๋า |
| ปุ่ม "ออกเดินตาม" กดไม่ได้ | ยังไม่ได้ต่อบอร์ด หรือยังไม่ได้เลือกเจ้าของ ย้อนไปขั้นที่ 2–3 |
| กระเป๋าไม่ขยับทั้งที่กดตามแล้ว | ตรวจว่าเปิดสวิตช์หลักและแบตเตอรี่แล้ว และสวิตช์ E-STOP ไม่ได้ถูกกดค้าง ตรวจว่ากรอบส้มยังอยู่ที่ตัวคุณ |
| กระเป๋าหยุด ๆ เดิน ๆ | เดินช้าลง ตรงขึ้น อย่าให้ใครบังกล้อง ตรวจว่าสัญญาณ Wi-Fi แรงพอ (อย่าเดินห่างจากตัวปล่อย Wi-Fi) |
| หลุดแล้วระบบหาเจ้าของไม่เจอ | ยืนนิ่งในภาพ 3–5 วินาที กด "หาเจ้าของ" หรือแตะตัวเองใหม่ ถ้าเปลี่ยนเสื้อผ้า ให้ "ลืมเจ้าของ" แล้วจำใหม่ |
| กระเป๋าตามผิดคน | กด **"หยุด!"** ทันที แล้ว "ยกเลิกที่เลือก" และแตะตัวเองใหม่ (คนที่แต่งตัวเหมือนกันแยกด้วยสีเสื้อไม่ได้) |
| เดินช้ากว่าคน | เดินช้าลงให้เท่าความเร็วกระเป๋า |

## 7. เคล็ดลับ

- **ลงทะเบียนในแสงและสถานที่เดียวกับที่จะใช้จริง** และใส่ชุดเดียวกับตอนใช้
- ถ้ามีคนอื่นแต่งตัวคล้ายกันอยู่ในภาพ ให้เจ้าของมี **ของสีสดที่ไม่มีใครมี** ติดที่ลำตัว (ผ้าคาดแขน เสื้อกั๊ก) แล้วกด "จำเสื้อผ้า" ตอนใส่ของนั้น
- ให้มือถือเย็นและมีไฟพอ (ถอดเคส ไม่วางกลางแดด) มือถือร้อนจะทำให้ระบบช้าลง
- ใช้เสร็จทุกครั้ง: กด "หยุด!" → "เลิกต่อ" → "ปิดกล้อง"

## 8. บัตรสรุป 5 บรรทัด

1. ตั้งมือถือบนกระเป๋า หันหาเจ้าของ → **กล้อง › เปิดกล้อง**
2. แตะตัวเอง → **เจ้าของ › จำเสื้อผ้า** แล้วหันข้าง/หลัง **+ มุม**
3. **บอร์ด › ต่อบอร์ด** (Wi-Fi เดียวกับกระเป๋า)
4. **ตาม › ออกเดินตาม** แล้วเดินช้า ๆ ตรง ๆ
5. ผิดปกติ → **หยุด!** และสวิตช์ E-STOP บนกระเป๋า
